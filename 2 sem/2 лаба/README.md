# Приложение для учета общественной работы студентов

Учебное оконное приложение на Python, выполненное по шаблону MVC.  
Программа позволяет добавлять записи о студентах, искать их по условиям варианта, удалять найденные записи, просматривать общий список и сохранять/загружать данные в формате XML.

## Возможности программы
- добавление записей через отдельное диалоговое окно;
- поиск записей по фамилии, группе и диапазону общественной работы;
- удаление записей по заданным условиям;
- отображение всех записей в главном окне;
- постраничный вывод записей.

## Структура проекта
- `models` — модели данных;
- `views` — главное окно;
- `controllers` — обработка действий пользователя;
- `dialogs` — дочерние окна добавления, поиска и удаления;
- `utils` — пагинация и работа с XML.

## Запуск программы
1. Убедиться, что установлен Python 3.
2. Открыть папку проекта.
3. Запустить файл:

```bash
python main.py
```

## Формат данных
Каждая запись содержит:
- ФИО студента;
- номер группы;
- значения общественной работы за 10 семестров.

## Примечание
Для демонстрации работы можно использовать готовые XML-файлы из папки `data_samples`.
